# sunshine

a system wide theme setter/manager and bootstraper for macOS inspired by [omarchy](omarchy.org)
all in a single shell script


## covers:

- VS code
- zed
- lazyvim
- iterm2
- btop
-  neofetch
-  yazi
-  wallpapers (WIP)
-  simplebar/Uberschicht
